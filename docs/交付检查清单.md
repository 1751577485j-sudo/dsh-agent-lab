# 视频交付前检查清单

本清单用于视频成片交付客户或上线发布前的最终自检。请逐项确认后勾选复选框；不适用项标注「N/A」并简要说明原因。建议由制作人自检、复核人复检，双方确认后再交付。

> 清单中的响度、尺寸、编码等具体数值为常见参考值，请以项目合同、目标平台或客户规范为准。

## 1. 分镜与成片一致性

- [ ] 成片镜头顺序与分镜脚本一致
- [ ] 各镜头时长、景别、机位、运镜与分镜一致
- [ ] 分镜中的文案、字幕、图形、特效均已落地
- [ ] 客户 / 导演确认的修改意见已全部落实
- [ ] 与分镜的合理偏离已记录原因并取得确认

## 2. 画面完整性（黑帧 / 掉帧）

- [ ] 全片逐段检查，无意外黑帧（含片头、片尾、转场）
- [ ] 无掉帧、卡顿、跳帧，播放帧率稳定
- [ ] 无花屏、闪烁、画面撕裂或异常跳变
- [ ] 时间线无空段、断轨或误入的占位素材
- [ ] 片头片尾时长符合要求，无多帧或少帧

## 3. 音频（响度 / 爆音 / 同步）

- [ ] 整体响度符合目标平台标准（参考：网络平台约 -14 LUFS，广电约 -23 LUFS，按项目要求调整）
- [ ] 峰值不超过 -1 dBTP，无削波、爆音
- [ ] 人声清晰，背景音乐与音效不压过解说
- [ ] 左右声道正常，无单声道、相位反转或声道缺失
- [ ] 音画同步，无口型错位、音效延迟
- [ ] 无杂音、电流声，底噪在可接受范围

## 4. 字幕与文案

- [ ] 字幕文案与最终解说 / 对白一致，无错别字、漏字、多字
- [ ] 专有名词、数字、单位、标点已逐条核对
- [ ] 断句合理，单行字数与停留时长符合规范
- [ ] 字幕位置不遮挡关键画面、人物面部或产品信息
- [ ] 多语言版本术语、译名统一
- [ ] 字幕形式（硬字幕 / 外挂字幕）与成片版本对应

## 5. 封面与包装

- [ ] 封面尺寸符合目标平台要求（如 16:9、9:16、1:1，常见 1920×1080、1080×1440）
- [ ] 封面比例与成片一致，画面无拉伸、变形、裁切错误
- [ ] 封面标题、LOGO 清晰可读，无错字、无遮挡
- [ ] 封面文件格式与大小符合上传限制
- [ ] 片头片尾、LOGO、角标、水印符合品牌规范
- [ ] 安全区检查：关键信息未超出画面安全区

## 6. 文件命名与格式

- [ ] 文件名符合「项目名-版本-类型」规范，例如：`品牌TVC-v3-成片.mp4`
- [ ] 版本号清晰（v1 / v2 / final 等），与交付记录一致
- [ ] 类型标识正确（成片 / 预告 / 花絮 / 横版 / 竖版等）
- [ ] 文件格式、编码、码率符合交付要求（如 MP4 / MOV，H.264 / H.265）
- [ ] 分辨率、帧率、色彩空间与项目要求一致
- [ ] 文件可正常播放，无损坏、无加密限制

## 7. 归档与交付

- [ ] 成片、字幕、封面、工程文件 / 素材已归档至指定位置
- [ ] 归档位置：________________（如 NAS / 网盘 / 项目管理系统），路径可访问
- [ ] 归档目录结构与命名规范一致
- [ ] 交付链接已生成，权限与有效期设置正确
- [ ] 交付清单 / 版本说明已同步给相关方
- [ ] 原始素材与工程文件保留备份

## 8. 发布前复核

- [ ] 全片完整播放一遍（含片头片尾）
- [ ] 在目标设备 / 平台上预览，效果正常
- [ ] 无版权或授权风险素材
- [ ] 敏感信息（人脸、车牌、隐私数据等）已处理
- [ ] 复核人确认并签字
